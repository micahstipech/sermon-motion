# House

The church's lasting memory for Stipech Motion, synced between machines through this repo.

- `brand/`: logo files, lockups and brand fonts. These are the only assets allowed to repeat across videos.
- `Sermon Series/<Series Name>/`: one folder per series: `Background*`, `Colors`, font files,
  `Example.png`, `Assets/` (transparent PNGs). The skill adds `kit.json` and `_stipech/`. See
  skills/motion-designer/references/series-folder.md.
- `rules.md`: every lesson from feedback, one line each. Read before every project.
- `ledger.json`: what each video used, so intros, outros and treatments never repeat.

`/mg-setup` points `~/.stipech-motion/config.json` at this folder.
